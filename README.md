# Một Ngày Mới — Phố Việt (GitHub Pages)

Đây là bản chơi đơn tĩnh để xuất bản bằng GitHub Pages.

## Đưa lên GitHub
1. Tạo repository mới, ví dụ `mot-ngay-moi-pho-viet`.
2. Upload `index.html`, `.nojekyll`, `README.md` lên thư mục gốc (root).
3. Vào **Settings → Pages**.
4. Trong **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/(root)`, rồi bấm **Save**.
6. Chờ GitHub triển khai; mở liên kết hiện trong mục Pages.

Lưu ý: GitHub Pages chỉ host nội dung tĩnh. Bản này chơi đơn. Đăng ký/đăng nhập, lưu tài khoản và multiplayer cần deploy `server.js` lên máy chủ Node.js riêng.
